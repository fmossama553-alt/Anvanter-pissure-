# LEONI Production & Bagouda Inventory

## Deploy on GitHub Pages
1. Create a repository.
2. Upload `index.html` into the repository root.
3. Go to Settings > Pages.
4. Choose Deploy from a branch, branch `main`, folder `/ (root)`, then Save.

## Use
- Add family: opens a form (not a browser prompt).
- Add model inside a family and select its type (Épissure / Fil / Torsadé / Autre).
- Enter quantities for Production and Bagouda; totals and report update instantly.
- Rename or delete families/models.
- Export CSV or print/save PDF.
- Data saves locally in this browser (not shared between phones/computers).
